# Android Date & Time Picker

A lightweight, customizable Android component built in Kotlin for picking dates and times seamlessly.

## Features

- 📅 **Date Picker:** Easy date selection with min/max date constraints.
- 🕒 **Time Picker:** 12-hour and 24-hour time support.
- 🎨 **Material Design:** Styled using Material Components for a modern look and feel.
- 🛠️ **Customizable:** Easily adapt colors, themes, and formats to match your app design.

## Prerequisites

- Android SDK version 21 (Android 5.0) or higher
- Android Studio Ladybug (or newer)
- Kotlin support enabled

## Installation

Add the repository to your root `settings.gradle.kts` (or `build.gradle`):

```kotlin
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
    }
}
